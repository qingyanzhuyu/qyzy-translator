服务商

每个服务商独立保存 API Key；翻译时只使用「当前」服务商。支持任何 OpenAI 兼容接口 （Base URL 到 /v1 为止）。

翻译

网页版会复用已登录的 chat.deepseek.com：自动填入提示词并点击发送，再把回复回填到译文块；需要保持该标签页打开，且属于自动化操作，可能受网页改版或风控影响。

低于该词数的段落不参与整页翻译，避免把按钮和导航翻乱；划选翻译不受限制。

预取只在没有正在进行的翻译时触发，每页最多 40 次；它会在你点击前消耗少量额度，不需要可关闭。

术语表会随每次请求一起发送；留空则只依赖模型自身知识。

翻译缓存 —

缓存按「服务商 + 模型 + 原文」保存，命中时不再请求 API；清除后不影响其他设置。

使用说明

第一次使用

  1. 选引擎：有 API Key 选「API」；想用网页版额度选「DeepSeek 网页版」。
  2. API 配置：到「服务商」填 Key → 测试连接 → 保存 → 设为当前。
  3. 网页版配置：在浏览器登录 chat.deepseek.com，关掉「深度思考」，保持标签页打开；点「译」时若没开会自动打开。
  4. 刷新一次目标网页，让内容脚本生效。

日常翻译

  • 鼠标悬停段落 → 点右上角「译」：译文插在原文下方。
  • 选中文字 → 点选区右上角「译」：只翻译选中的部分。
  • 整页翻译：右下角圆形按钮、弹窗「翻译本页」，或 Alt+Shift+T。
  • 译文块顶部可复制、重试、关闭；标题显示「模型 · 总耗时（首字 x.x s）」。

代码与公式

代码、公式、行内代码会以 [[C0]] 占位符发送，返回后原样回填；网页版丢失占位符会直接报错，不会悄悄少代码。

自定义外观

  • 设置页背景：替换 assets/background.jpg（建议 1600×900、深色低对比），然后在扩展页重新加载。
  • 头像 / 徽标 / 图标：分别替换 icons/avatar.png、icons/hat.png、icons/icon16/32/48/128.png。
  • 背景浓淡：编辑 src/options.css 里 body::before 的 opacity，默认 0.09。

常见问题

  • 首字 20–40 秒：模型在深度思考，换非推理模型或尝试 {"thinking_mode": false}。
  • 401 / 403：Key 无效；429：触发限流，等一分钟。
  • 网页版“找不到输入框”：未登录或未打开 chat.deepseek.com。
  • 更新扩展后没效果：在扩展页重新加载，并刷新目标网页和 DeepSeek 标签页。

完整说明与常见问题见项目根目录的 README.md。
