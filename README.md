# QYZY·translator

面向竞赛编程题面和英文技术页面的浏览器翻译扩展。译文直接插在原文下方，代码、公式、行内代码原样保留。

支持 Edge / Chrome，Manifest V3。

---

## 第一次使用（5 分钟）

### 1. 安装扩展

**Edge**

1. 打开 `edge://extensions/`；
2. 打开左下角「开发人员模式」；
3. 点「加载解压缩的扩展」，选择本文件夹 `edge-translator`；
4. 工具栏出现礼帽图标即安装成功。

**Chrome**

1. 打开 `chrome://extensions/`；
2. 打开右上角「开发者模式」；
3. 点「加载已解压的扩展程序」，选择本文件夹。

> 这是未上架商店的本地扩展，Edge/Chrome 可能会提示“来源未知”，正常允许即可。换电脑时需要重新加载一次。

### 2. 选择翻译引擎（二选一）

点工具栏图标 → ⚙ 进入设置 →「翻译」→「翻译引擎」。

| 引擎 | 适合谁 | 需要什么 |
|---|---|---|
| **API（服务商）** | 有 API Key，想要稳定和速度 | 一个 OpenAI 兼容的 Key |
| **DeepSeek 网页版** | 没有 Key，想用网页版额度 | 浏览器里登录 chat.deepseek.com |

---

## 方案 A：用 API 引擎

1. 设置 →「服务商」→ 选一个模板（默认 Intern TokenPlan）；
2. 粘贴 API Key；
3. 点「测试连接」，显示「连接成功（首字 x.x s）」即可；
4. 点「保存设置」；
5. 点「设为当前」，确保卡片右上角显示「当前」。

内置模板：

| 服务商 | Base URL |
|---|---|
| Intern TokenPlan | `https://discovery-api.intern-ai.org.cn/v1` |
| OfoxAI | `https://api.ofox.ai/v1` |
| DeepSeek 官方 | `https://api.deepseek.com/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| 本地 Ollama | `http://localhost:11434/v1`（无需 Key） |

每个服务商独立保存 Key，翻译只用「当前」那个；弹窗里也能快速切换。

> 模型如果首字要 20–40 秒，通常是模型强制“深度思考”。优先试 `Atria-Dawn`、`intern-s2`（额外参数 `{"thinking_mode": false}`）或其他非推理模型。

---

## 方案 B：用 DeepSeek 网页版引擎

1. 在浏览器打开 `https://chat.deepseek.com` 并登录；
2. **手动关闭「深度思考」**（否则一样会等几十秒）；
3. 这个标签页保持打开，不要关；
4. 设置 →「翻译」→ 引擎选「DeepSeek 网页版」→ 保存；
5. 回到题目页点「译」。

扩展会自动：填入提示词 → 点击发送 → 读取回复 → 回填译文块。如果还没有打开 DeepSeek 标签页，点「译」时会自动打开。

**对话轮换**：每完成 N 次翻译（默认 8，可改），会自动删除当前对话并新开一个，避免上下文越积越长。删除失败时会退回“只新开、不删除”，不影响翻译。

> 网页版是自动化操作，可能受 DeepSeek 改版或风控影响；账号风险需自行承担。如果网页端也开着深度思考，速度不会比 API 快。

## 日常使用

| 操作 | 效果 |
|---|---|
| 鼠标停在段落上 → 点右上角「译」 | 在原文下方插入该段译文 |
| 选中文字 → 点选区右上角「译」 | 翻译选中部分 |
| 右下角圆形「译」按钮 | 翻译整页 |
| `Alt + Shift + T` | 翻译整页 |
| 扩展弹窗「翻译本页」 | 翻译整页 |
| 扩展弹窗「清除译文」 | 移除当前页所有译文块 |

译文块顶部有「复制 / 重试 / 关闭」，标题会显示 `模型 · 总耗时（首字 x.x s）`，方便判断是模型慢还是网络慢。

**代码与公式**：`pre`、`code`、行内代码、KaTeX/MathJax 公式会替换成 `[[C0]]` 这类占位符发给模型，返回后原样回填。网页版如果丢了占位符，会直接报错而不是悄悄少一段代码。

## 设置项说明（设置 → 翻译）

| 选项 | 默认 | 作用 |
|---|---|---|
| 翻译引擎 | API | API 或 DeepSeek 网页版 |
| 网页版每 N 次翻译后新开对话 | 8 | 超过 N 次删除当前对话并新开 |
| 整页翻译最短英文词数 | 4 | 低于该词数的段落不参与整页翻译 |
| 显示右下角悬浮按钮 | 开 | 关闭后只能用弹窗/快捷键翻整页 |
| 悬停预取 | 开 | 停留 350ms 提前翻译；需要缓存开启才有意义 |
| 使用翻译缓存 | 关 | 相同段落命中缓存秒回；默认关闭 |
| 预取停留时长 | 350ms | 调大更省额度，调小更跟手 |
| 使用术语表 | 开 | 术语表只对 API 引擎生效 |
| 术语表 | 内置 | 每行「英文=中文」，可增删 |

缓存最多保存 400 条、约 150 万字符，超出按最久未用淘汰；「清除缓存」会立即清空。

## 自定义外观（背景 / 头像 / 图标）

扩展的视觉素材都是本地图片，**替换同名文件 + 重新加载扩展**即可，不需要改代码。

| 文件 | 用途 | 建议规格 |
|---|---|---|
| `assets/background.jpg` | 设置页底纹、设置页顶栏 | 1600×900 左右，深色/低对比，避免影响文字 |
| `icons/avatar.png` | 弹窗顶部、设置页「关于」头像 | 正方形，256×256，建议透明或圆角 |
| `icons/hat.png` | 译文块左上角徽标 | 正方形，透明底 PNG，256×256 |
| `icons/icon16.png` / `icon32.png` / `icon48.png` / `icon128.png` | 浏览器工具栏、扩展列表图标 | 对应尺寸的正方形 PNG |

**步骤**

1. 用自己的图片覆盖上表对应文件（文件名、扩展名保持一致）；
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`），点扩展卡片上的「重新加载」；
3. 重新打开设置页，背景会自动更新。

**想换文件名或格式**

- 背景：改 `src/options.css` 里两处 `url('../assets/background.jpg')`；
- 徽标：改 `src/content.js` 中 `chrome.runtime.getURL('icons/hat.png')`；
- 头像：改 `src/popup.html` 和 `src/options.html` 中 `icons/avatar.png` 的引用。

**调整背景浓淡**

设置页底纹的透明度在 `src/options.css` 的 `body::before { opacity: ... }` 里，默认 `0.09`；顶栏叠加在 `.top` 的 `background` 中，可按需调低。

> 背景图只在本地使用，不会上传到任何服务器；换图后如果没变化，确认替换的是扩展目录里的文件，并重新加载了扩展。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 测试连接提示 401/403 | Key 错误或无权限，重新复制 Key |
| 首字 20–40 秒 | 模型在深度思考，换非推理模型或关思考 |
| 提示 429 / 请求过于频繁 | 触发服务商限流，等 1 分钟再试 |
| 提示“请求超时” | 网络或模型排队，点「重试」或换模型 |
| 提示“模型没有返回正文” | 关思考参数导致空响应，清空额外参数或换模型 |
| 网页版提示“找不到输入框” | 没打开/没登录 chat.deepseek.com，或标签页被关 |
| 网页版提示“发送按钮不可用” | 网页正在生成上一条，等它结束再点 |
| 网页版提示“丢失代码占位符” | 模型改写了占位符，点重试；仍失败就换 API 引擎 |
| 网页版一直“翻译中” | 网页 DOM 改版或卡住；看网页端是否已回复，必要时刷新 |
| 更新扩展后没效果 | 需要在扩展页重新加载，并刷新目标网页和 DeepSeek 标签页 |
| 整页翻译漏段 | 页面是动态加载的，滚动后再点一次整页翻译 |

## 数据与隐私

- 只有你点击「译」、划选翻译或整页翻译时，才会把对应文本发给所选服务商/网页版；
- 开启「悬停预取」后，鼠标停留会提前发送该段文本（默认缓存关闭，所以默认不会预取）；
- API Key 保存在 `chrome.storage.local`，页面脚本读不到；
- 翻译缓存、设置都只存在本机浏览器，不会上传到任何自建服务器；
- 扩展不含远程代码，全部逻辑打包在文件夹内。

---

## 已知限制

- 只支持 OpenAI 兼容接口；Anthropic Messages / Gemini 原生协议需要走各家的 OpenAI 兼容端点；
- 译文以纯文本 + 轻量 Markdown（标题、列表、粗体、行内代码、围栏代码块）呈现，不保留原网页排版；
- 整页翻译按块级元素扫描，SPA 动态内容需要滚动后再点一次；
- DeepSeek 网页版引擎依赖网页 DOM，改版后可能失效，需要更新选择器；
- 未上架应用商店，不自动更新，换电脑需手动复制文件夹并重新填 Key。

---

## 卸载 / 更新

- 更新：用新文件夹覆盖旧文件夹，然后在扩展页点「重新加载」；
- 卸载：扩展页点「移除」，本机保存的 Key、设置、缓存会一并删除；
- 换电脑：复制整个文件夹 → 加载 → 重新填 Key / 登录 DeepSeek。
